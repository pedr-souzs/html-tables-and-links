# HTML Tables and Links

Projeto de prática em HTML desenvolvido para explorar a criação e organização de informações utilizando tabelas e links.

## Sobre o projeto

O projeto reúne dois exercícios voltados aos fundamentos de HTML.

O primeiro apresenta uma tabela com nomes de sites e seus respectivos links, permitindo praticar a criação de tabelas e a utilização de elementos de navegação.

O segundo apresenta uma tabela de contatos, utilizando recursos de organização de conteúdo como cabeçalho, corpo da tabela e mesclagem de colunas.

## Exercícios

### Tabela de sites e links

Criação de uma tabela contendo:

* Nome do site
* Link de acesso

A atividade utiliza links HTML para direcionar o usuário aos respectivos sites.

### Tabela de contatos

Criação de uma tabela para organização de informações de contato, utilizando:

* Cabeçalho da tabela
* Corpo da tabela
* `colspan`
* Linhas e células

## Tecnologias utilizadas

* HTML5

## Conceitos praticados

* Estrutura básica de documentos HTML
* Elemento `table`
* Linhas com `tr`
* Cabeçalhos com `th`
* Células com `td`
* `thead` e `tbody`
* `colspan`
* Links com `a`
* Atributo `href`
* Organização de informações em tabelas

## Objetivo

Praticar os fundamentos de HTML por meio da criação de tabelas e links, desenvolvendo familiaridade com a estruturação de dados e os principais elementos utilizados para organizar informações em páginas web.
