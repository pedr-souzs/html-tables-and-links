# HTML Tables and Links

![HTML5](https://img.shields.io/badge/HTML5-E34F26?logo=html5&logoColor=white)

Conjunto de exercícios introdutórios de **HTML5** voltados à criação de tabelas, organização de informações e navegação por links.

## Sobre o projeto

O repositório reúne duas páginas independentes: uma tabela com links de sites e uma tabela de contatos. O objetivo é exercitar a estrutura básica de dados tabulares.

## Exercícios

### 1. Tabela de sites e links — `Table-Links.html`

Apresenta três sites (Google, YouTube e GitHub) e seus respectivos endereços, utilizando o elemento `a` com o atributo `href`.

### 2. Tabela de contatos — `Table.html`

Apresenta um exemplo de tabela com cabeçalho de duas colunas, agrupamento do cabeçalho com `colspan` e informações no corpo da tabela.

## Tecnologias utilizadas

- HTML5.

## Conceitos praticados

- Estrutura de documento HTML.
- Tabelas com `table`, `tr`, `th` e `td`.
- Separação entre cabeçalho (`thead`) e corpo (`tbody`).
- Mesclagem de células com `colspan`.
- Links HTML e atributo `href`.

## Estrutura

```text
html-tables-and-links/
├── Table-Links.html
├── Table.html
└── README.md
```

## Como executar

1. Clone ou baixe o repositório.
2. Abra `Table-Links.html` no navegador para visualizar os sites e links.
3. Abra `Table.html` para visualizar a tabela de contatos.

Não há dependências externas.

## Notas de estudo

Os arquivos registram exercícios iniciais. A marcação de `Table.html` ainda pode ser revisada para corrigir abertura e fechamento de elementos HTML. Ao publicar exemplos de contato, prefira dados fictícios para preservar a privacidade.

## Objetivo

Praticar a organização de informações estruturadas e compreender a semântica dos elementos de tabela e de navegação.
